# src/assets

Game assets imported from code (sprites, tiles, fonts, audio) live here so Vite
fingerprints them. Empty on purpose in GAME-00.

Rules (see docs/GAME_CONSTITUTION.md):

- Only original assets or assets with a license that allows this use.
- Record origin + license of every third-party file in `docs/ASSETS.md`
  (create it with the first asset).
- Never add Pokémon/Nintendo (or any other protected IP) sprites, sounds,
  music, logos, fonts or tilesets.
