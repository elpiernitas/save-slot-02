# SAVE SLOT 02 — Final Save Slot UI

Status: GAME-09 UI direction.

## Purpose

Persistent home after completion.

This should look like the title/save interface has finally become complete.

## Layout

Left/centre:
`SAVE SLOT 02`

Status rows:
- PLAYER 1
- CLASS
- PLAYER 2
- SIDE QUEST
- DATE ROUTE

Right:
small paired character visual or calm city thumbnail.

Bottom menu:
- OPEN SAVE
- CITY CARDS
- SETTINGS

Optional later:
- POST-GAME entry when GAME-10 unlocks content.

## Status language

Before reveal:
`PLAYER 2 — ???`

After reveal:
`PLAYER 2 — MANU`

Before date:
`DATE ROUTE — UNRESOLVED`

After date:
canonical chosen label.

Final:
`STATUS — COMPLETE`

Avoid showing dozens of flags or debug percentages.

## Animation

First completion:
- slot border resolves from noisy to clean;
- one short save pulse;
- status rows populate sequentially.

Subsequent visits:
- near-instant;
- no replay of full ending.

Reduced motion:
instant rows.

## Card access

If GAME-05 exists:
CITY CARDS button opens binder.

Do not force the player back into overworld.

## Returning to world

Not required.

If future post-game content needs world access, add it deliberately in GAME-10.
