# GAME-08 — Date Gate Copy Direction

Status: writing guide.

## Reveal line

The scene can finally be explicit that the route is real.

Keep it short.

Possible narrator direction:
`Vale. Esta parte sí sale fuera del juego.`

Possible Manu direction:
`elige día y yo hago como que todo esto era un plan perfectamente normal.`

Do not use both if one is enough.

## Gate labels

System copy remains English-retro.

### Wednesday
`WED · 30 SEP`

Optional sublabel:
`MIDWEEK ROUTE`

### Thursday
`THU · 01 OCT`

Optional:
`ALMOST WEEKEND`

### Friday
`FRI · 02 OCT`
`MAIN QUEST ALREADY ACTIVE`
`18:30 · THEATRE`

### Sunday
`SUN · 04 OCT`

Optional:
`SUNDAY SIDE QUEST`

## Confirmation

`LOCK THIS ROUTE?`

Then human-readable:
`Thursday · 1 October`

Buttons:
- YES
- BACK

## After confirmation

`ROUTE LOCKED`

Short pause.

`SAVING...`

Then GAME-09.

Avoid:
- "Will you go on a date with me? yes/no";
- giant love declaration;
- proposal-like language;
- guilt if a date is not chosen.
