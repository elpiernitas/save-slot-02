# GAME-06 — Content Flow

Status: narrative/mechanical planning.

## Entry condition

GAME-05 completed enough to establish:
- exploration rewards exist;
- CITY CARDS/inventory are understood.

GAME-06 begins after La Muralla's route data updates.

## Sequence

### 01 — Route update

SYSTEM:
`SIDE QUEST ROUTE UPDATED`

Small dialogue:
`Hay una ruta nueva. Eso normalmente sería una buena noticia.`

Do not explain destination emotionally.

### 02 — Cholo arrival

Location:
`CIMAVILLA · TARDE`

The visual transition from La Muralla should feel like walking to another
nearby node, not teleporting into a fantasy level.

One or two ambient interactables before the first puzzle.

### 03 — ROUTE BEACONS

Three city objects pulse with symbols.

Sample symbols:
- wave;
- lamp;
- cup.

The sequence should be visible through:
- the first pulse;
- subtle persistent symbol marks.

Example system:
`ROUTE CALIBRATION REQUIRED`

Wrong:
`SEQUENCE REJECTED.`
Narrator:
`Muy dramático para tres cosas en una calle.`

Success:
`ROUTE SYNC — OK`

Reward option:
`CITY CARD ADDED — AFTERNOON IN CIMAVILLA`

### 04 — optional seagull

Trigger:
snack/bag/bench interaction.

Narrator:
`Error táctico: parecer que tienes comida.`

SYSTEM:
`SEAGULL PROTOCOL`

Clear:
`THREAT LEVEL: UNREASONABLY PERSONAL`

Reward:
`CITY CARD #003 — SEAGULL WITH INTENT`

Leave:
no penalty.

### 05 — route anomaly

After beacons, a system access point appears/activates.

Do not call it "dungeon" in UI.

Possible label:
`SERVICE ACCESS`
or
`ROUTE NODE`.

### 06 — SYNC TERMINAL

Display:
```
PLAYER 1 INPUT    PLAYER 2 INPUT
[ ACTIVE ]        [ NO SIGNAL ]
```

Luis solves left path.

After solution:
`PLAYER 1 — SYNCED`

System checks second side.

Pause.

`PLAYER 2 — NOT FOUND`

Narrator:
`Eso parece... menos opcional de lo que debería.`

Then:
`FALLBACK ROUTE AVAILABLE`

Confirm.

### 07 — corrupted recovery

Very short transition.

`RECOVERING MISSING INPUT...`
`...`
`RECOVERY PROCESS ERROR`

The system entity/boss signal appears.

End GAME-06.

GAME-07 begins from this state.
