# SAVE SLOT 02 — Story Bible

Status: narrative planning source of truth. This does **not** override
`GAME_CONSTITUTION.md` or `WORLD_BIBLE.md`.

## Premise

Luis opens a private link expecting a small game and discovers an apparently
unfinished save file that identifies him as PLAYER 1. The system claims that
an unidentified side quest has been attached to his save.

The game never begins by saying "this is about a date" or "this is about
Manu". The first half should work as a genuinely playable, slightly strange
urban RPG set in a compressed version of Gijón.

The final reveal is not "look at our memories". It is:

> the strange quest has been preparing a real-world plan that still has to be
> chosen and played.

## Narrative rules

- Gijón is a playable world, not a slideshow of memories.
- Recognisable details are rewards for attention, not exposition.
- Do not narrate Manu and Luis's history chronologically.
- Do not over-explain references.
- Keep emotional beats short.
- Humour is dry and often comes from RPG logic applied to ordinary life.
- "Epic" setup may resolve into something mundane.
- No tarot-as-destiny framing.
- PLAYER 2 must feel earned.
- The date choice is a late-game reward, not the visible objective.

## Language

- SYSTEM / save / quest / menus: English retro UI language.
- Narrator / characters: Spanish.
- Avoid faux-medieval fantasy diction.
- Luis and Manu should sound contemporary and natural.

## Structure

### ACT 0 — SYSTEM

Already implemented:
- system check;
- fullscreen;
- boot;
- SAVE DATA FOUND;
- title;
- class selection.

Purpose: establish that the browser is behaving like a game system.

### ACT I — THE UNIDENTIFIED SIDE QUEST

Primary location: La Muralla / Cimavilla, afternoon.

Luis enters the first real space alone.

Objectives:
- teach movement and interaction;
- prove the game knows recognisable details without explaining why;
- establish the "ordinary life treated as RPG" tone;
- give first low-stakes item/card hooks when GAME-05 exists.

Do **not** explain why La Muralla matters.

Suggested quest language:
- `SIDE QUEST: ???`
- `OBJECTIVE DATA CORRUPTED`
- the world gives small tasks anyway.

### ACT II — GIJÓN OPENS

The playable world expands through several compressed "district nodes", not a
full open-world city.

Potential nodes:

1. **Cimavilla / Cuesta del Cholo — afternoon**
   - people sitting outside;
   - friends / social atmosphere;
   - small dialogue puzzle or observation challenge.

2. **Errand district — morning**
   - mundane supply run framed as heroic preparation;
   - wholesale-sidra reference can become a fictional warehouse/supply shop;
   - furniture-store cafeteria reference can become a recovery stop;
   - do not use real brands unless deliberately approved.

3. **Coast / San Lorenzo — sunset**
   - quieter pacing;
   - environmental puzzle;
   - sea / promenade;
   - room for one subtle emotional beat without a speech.

4. **Night district**
   - bar / nightlife energy;
   - Hoyo 13 may appear only as a small secondary reference;
   - not the centre of the relationship or game.

The acts do not need to represent one literal day.

### ACT III — THE SAVE IS MISSING SOMEONE

The system begins showing anomalies that suggest the quest state expects two
players.

Examples:
- a door requires `2 PLAYERS`;
- a puzzle has an unused second input;
- inventory contains a blank second slot;
- NPC refers to "el otro jugador" without identifying anyone.

Do not reveal Manu yet.

### ACT IV — BOSS / PLAYER 2

GAME-07.

The "boss" should be playful and mechanically satisfying rather than a
villain representing relationship problems.

PLAYER 2 appears after the boss condition is met.

MANU:
- black hoodie;
- black rectangular glasses;
- recognisable dark voluminous hair;
- enters as PLAYER 2, not as a romantic monologue.

Desired reveal feeling:
"ah, claro, eras tú" rather than "surprise, this was a love letter".

After reveal, one short cooperative sequence can use the two-player fiction
without requiring a second real controller.

### ACT V — PORTALS / DATE GATE

GAME-08.

The quest finally identifies its real-world reward.

Selectable:
- Wednesday 30 September 2026;
- Thursday 1 October 2026;
- Sunday 4 October 2026.

Friday 2 October 2026:
- visible;
- not selectable;
- `MAIN QUEST ALREADY ACTIVE`;
- existing theatre plan at 18:30 and possible later plans.

Presentation:
- three portals / save destinations / calendar gates;
- class and prior choices may alter flavour text, never availability;
- choosing a date writes the save and cannot be changed accidentally.

### ACT VI — END / SAVE SLOT

GAME-09.

After choosing:
- confirm chosen date clearly;
- avoid overlong romantic payoff;
- return to save-slot language;
- show that the file is no longer "incomplete";
- preserve the website as a persistent save.

Suggested status evolution:
- `STATUS: INCOMPLETE`
- `SIDE QUEST: ACTIVE`
- `PLAYER 2: FOUND`
- `DATE QUEST: LOCKED IN`
- `SAVE SLOT 02: CONTINUE?`

## Personal references — approved pool

Use sparingly. Not all must appear.

- La Muralla as first-meeting location;
- Luis's large Steam library (~1400 games) as an optional joke/easter egg;
- Minecraft as a familiar game reference;
- old Pokémon-card collection as inspiration for GAME-05 cards, without
  copying Pokémon IP;
- Club Penguin as a tiny nostalgia reference if it fits;
- cinema as a recurring normal plan;
- Cuesta del Cholo;
- sidra / buying supplies;
- friends / Discord / social gaming atmosphere;
- Randy as a later secondary NPC;
- Three of Swords reversed only as a subtle optional tarot easter egg;
- Spider-Man / Doctor Strange references should remain oblique or omitted
  unless a non-IP joke can be made.

## Randy

Randy is recognisable, not magical.

Good use:
- appears sitting somewhere;
- notices an item;
- blocks a route for a few seconds;
- gets one dry narrator line;
- can be interacted with and then simply continues existing.

Bad use:
- chosen animal;
- quest oracle;
- mascot who follows the whole game;
- plot key.

## Emotional ceiling

The game can be affectionate, but the emotional register should remain:
- playful;
- specific;
- understated.

Avoid:
- "you changed my life";
- destiny / soulmate claims;
- speeches about the relationship;
- recreating breakups or sensitive personal history;
- turning private chat messages into quotations without an explicit reason.

## Current narrative gate

Do not write final GAME-05+ dialogue until GAME-04R's visual slice is
approved. Mechanics/content can be planned, but the first playable world must
look right before the scope expands.
