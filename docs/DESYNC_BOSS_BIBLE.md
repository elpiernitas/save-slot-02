# SAVE SLOT 02 — DESYNC PROCESS Boss Bible

Status: encounter design source of truth.

## Identity

Name:
`DESYNC PROCESS`

Internal:
`boss.desync_process`

It is:
- a failing synchronisation process;
- a visualised system error;
- a mechanical obstacle.

It is not:
- a villain;
- Manu;
- Luis;
- an ex;
- "fear of commitment";
- relationship trauma;
- destiny.

## Visual language

Shape family:
- rectangles;
- broken signal lanes;
- node circles/squares;
- duplicated UI fragments;
- offset scan blocks.

Palette:
- navy base;
- pale cyan;
- terminal green;
- cream;
- coral danger.

Use red sparingly.

## Encounter rhythm

Teach → combine → reveal missing channel.

The player should understand why PLAYER 2 matters through mechanics before
the reveal scene says who PLAYER 2 is.

## Telegraphs

Every hazard:
1. preview shape;
2. warning beat;
3. resolve;
4. recovery gap.

No surprise hits.

## Hits

Recommended three-strike integrity:
- `SIGNAL 3/3`
- `SIGNAL 2/3`
- `SIGNAL 1/3`

Avoid hearts/HP if it implies combat.

## Stabilisation

Near a node:
`E — STABILISE`

Hold is optional, but tap/short interaction is preferable to avoid accessibility
issues.

A node should take 1–2 seconds total, interruptible by movement.

## Pattern vocabulary

### BAR SWEEP
A wide horizontal/vertical block moves across the arena.

### PULSE
One or more circles/rectangles warn, then activate.

### SPLIT
Safe lane moves from one side to another.

### CHECKER
A few tiles alternate danger/safe.

Keep maximum simultaneous complexity low.

## Determinism

Patterns should be generated from a fixed seed per attempt or from static
sequences.

Tests must reproduce them.

## Assist mode

Offer after repeated failure.

Copy:
`ASSIST MODE AVAILABLE`

Options:
- ENABLE
- NOT NOW

Effect:
- slower hazard velocity;
- longer warning window;
- no story penalty.

## Defeat aesthetic

Do not explode.

The process should:
- stabilise;
- collapse into clean lines;
- resolve UI noise;
- expose the missing channel.

This makes the reveal feel like the system becoming legible.
