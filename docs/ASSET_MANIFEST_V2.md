## Reference-vs-runtime rule

A generated concept may contain:
- invented text;
- illustrative icons;
- speculative menu items;
- impossible perspective;
- non-canon content.

Claude must extract visual language, not copy every detail as game logic.

When in doubt:
**product docs control behavior; visual references control appearance.**
