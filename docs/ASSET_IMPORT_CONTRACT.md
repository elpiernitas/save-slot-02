# SAVE SLOT 02 — External art import contract

Status: authoritative for GAME-04R.

The visual assets for GAME-04R are produced **outside Claude Code** under
ChatGPT art direction. Claude Code is the integrator, not the image generator.

## Do not use paid image-generation connectors

- Do **not** use Higgsfield or any paid/credit-consuming image connector.
- Do not spend user credits to generate art.
- Do not attempt to imitate ChatGPT image generation by procedurally drawing
  the final scene in code.
- The existing `tools/art` generator may remain only as a development
  placeholder / regression fixture until approved raster assets replace it.

## Division of responsibilities

### ChatGPT / art direction
Produces or approves:
- environment concept;
- production background;
- character sprite references;
- prop sheet;
- portrait references.

### Claude Code / implementation
Does:
- import raster PNG assets;
- define anchors / frames / manifests;
- integrate them into Canvas 2D;
- align collisions to visible geometry;
- preserve movement, input, save, dialogue and camera;
- run tests and visual QA.

Claude must **not redraw or reinterpret approved art** unless explicitly asked.

## Asset interface

Expected target paths (names can be adjusted once files exist):

```
src/assets/world/muralla/
  background-afternoon.png
  foreground-afternoon.png
  player-luis.png
  npc-waitress.png
  props.png
  manifest.json
```

The loader should support replacing an image file without rewriting game logic.

### World
- logical view: 640×360 unless later approval changes it;
- nearest-neighbour scaling;
- no runtime smoothing;
- static background can exceed the viewport if camera movement requires it.

### PLAYER 1
- minimum frame: 32×48;
- 4 directional rows: down / up / right / left;
- columns: idle / step A / step B;
- ground anchor near centre of feet;
- collision footprint must be smaller than the sprite body.

### Props / foreground
Every separate y-sorted prop needs:
- sprite id;
- frame dimensions;
- ground anchor;
- optional animation period.

Permanent architecture should normally be baked into the background rather
than decomposed into dozens of props.

## Current state

The PNG files generated by `npm run art` are **not approved production
assets**. They prove the asset-loading pipeline and may be replaced file by
file.

When approved external assets arrive:
1. place files in the asset folder;
2. update manifest;
3. update map positions/colliders;
4. remove replaced items from the procedural generator;
5. keep tests for image dimensions, manifest integrity and map reachability;
6. create the six screenshots required by
   `docs/GAME_04R_VISUAL_REBUILD.md`.

## Blocking rule

If approved external raster assets are not available, **STOP visual work**.
Do not substitute paid generation, generic stock art, or new procedural art.

Technical work may continue only when it does not advance GAME-05 or alter
the approved visual target.
